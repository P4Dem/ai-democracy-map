The AI–Democracy Map diagrams

Real numbers pulled from the 206-entry research dataset — not mockup data. All three questions now show only the client's original diagram style (bubble-pack / node-link / force-cluster) — the directions already settled on — at roughly production size, with real interactivity added on top.

1

Which democracy aspects are more frequent across threats?

14 aspects across 4 pillars. Each entry's aspects are tagged PRIMARY or SECONDARY in the source data — the exact count of each is available on hover. Shown at roughly the width it would actually render on the site, not squeezed into a comparison column.

CBubble-pack
Circle area = total mentions, colored by pillar.

Interactivity

  • Hover a bubble → exact count, primary/secondary split, and definition — no ambiguity about "roughly how big" two close-in-size bubbles are.
  • Click a bubble → entries list filters to that aspect, and every other bubble fades so it's the only one you're looking at (click again, or the background, to reset).
  • Drag a bubble to pull a crowded cluster apart.

Circle area = total mentions. Click a bubble to isolate it, or hover for the exact primary/secondary split.

Compared to the original design

  • Same visual form — circle size, color, and layout are unchanged.
  • Hover now shows the exact count and primary/secondary split, instead of judging circle size by eye.
  • Click now isolates a bubble (fades every other one); the original did nothing on click.
  • Bubbles can be dragged apart to work a crowded cluster.

Which mechanism is more frequently involved in harming democracy?

8 tiers, context (T0) through societal downstream (T7). Source data confirms entries can carry up to 7 mechanism codes each, often jumping non-adjacent tiers — so a literal "straight line" flow per entry doesn't exist in the data. Shown at roughly the width it would actually render on the site, not squeezed into a comparison column.

CTiered node-link
Line color and number both scale with real co-occurrence strength — darker/redder + higher number = these two mechanisms appear together more often.

Interactivity

  • Hover a connecting line → that one line bolds, every other line fades, and a tooltip gives the exact count + both mechanism names — no ambiguity about which number belongs to which line in a crowded area.
  • Click a node → entries list filters to that mechanism, and all of its connections bold at once (hover isolates just one).
  • Drag a node to pull a crowded cluster apart.

Line color + number = real co-occurrence count. Hover a line to isolate it, or click a node for all its connections.

Compared to the original design

  • Same 8-tier relationship view — same columns, same connecting lines.
  • Connection strength is now readable directly, three ways: line color, line thickness, and a number printed on the line.
  • Hover isolates one connection at a time (bolds it, fades the rest); the original left every line visible with only thickness to judge by eye.
  • Click a node to isolate all of its connections at once; drag a node to pull a crowded cluster apart.
